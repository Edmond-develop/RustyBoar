Imperial.glb — грузовой корабль из набора Quaternius "Ultimate Spaceships" (лицензия CC0),
сконвертирован из OBJ + текстуры Imperial_Orange.png в один файл .glb.
Игра сама находит модель в этой папке и делает из неё вмёрзший корабль.
Если положить сюда несколько моделей — возьмётся первая по алфавиту.
